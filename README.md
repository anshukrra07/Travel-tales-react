# Travel Tales - React App

This is the React version of the Travel Tales website, converted from the original HTML/CSS/JavaScript project.

## Getting Started

### Installation

1. Navigate to the react-app folder:
```bash
cd react-app
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser to `http://localhost:5173`

## Features

✅ Homepage with all sections (Hero, Categories, About, Destinations, Activities)
✅ Header with navigation and search
✅ Login/Signup with backend authentication
✅ User account page
✅ Place details page
✅ Search results page
✅ Responsive design
✅ Backend API integration (auto-detects localhost/production)

## Backend Integration

- **Local**: `http://localhost:5001`
- **Production**: `https://travel-tales-f0hb.onrender.com`

Make sure your backend server is running for full functionality.

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
